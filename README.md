# ModuleForge

ModuleForge is a visual platform and deployment engine for composable and reusable software modules.

## Features
- **Visual Module Builder**: Connect and configure UI and backend modules seamlessly.
- **Team Workspace & Realtime Communication**: Channels, direct messages, and HD video/audio meetings.
- **Git & Deployment Integration**: Automatic sync, rollbacks, and instant Vercel/serverless deployment.
- **Antigravity IDE Support**: Direct one-click export and launch in Antigravity.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
